செம ஸ்பீடு ப்ரோ! இதோ நம்ம இன்டர்வியூ அஜெண்டால அடுத்த முக்கியமான டாபிக்: **Hoisting (ஹாய்ஸ்டிங்)**.

இன்டர்வியூல "Hoisting-னா என்ன?" அப்படின்னு கேட்டா நிறைய பேர் பயப்படுவாங்க. ஆனா, இது ரொம்ப ஜாலியான ஒரு கான்செப்ட்.

### நம்ம கதை: மேஜிக் ஷோவும் மாயாஜாலமும்! 🎩🐇

ஜாவாஸ்கிரிப்ட் அப்படிங்கிறது ஒரு **மேஜிசியன் (Magician)** மாதிரி.

மேஜிக் ஷோ ஆரம்பிக்கிறதுக்கு முன்னாடி, மேஜிசியன் என்ன பண்ணுவார்? ஸ்டேஜ்ல இருக்கிற எல்லா பொருட்களையும் (Variables & Functions) எடுத்து ரெடியா எடுத்து மேல (Top) வச்சிருவார். ஷோ நடக்கும்போது ஈஸியா யூஸ் பண்றதுக்கு தான் இந்த ஏற்பாடு. இதுக்கு பேருதான் Hoisting.

இப்போ ஷோ நடக்குது, நீங்க ஆடியன்ஸ்:

**1. Function (மேஜிக் முயல்):**
மேஜிசியன் அந்த முயலை வெளிய எடுக்குறதுக்கு முன்னாடியே, நீங்க "முயல் குட்டியை காட்டுங்க!" அப்படின்னு கத்துறீங்க. மேஜிசியன் கூலா தொப்பியில இருந்து முயலை கரெக்டா வெளிய எடுத்து காட்டிடுவார். (ஏன்னா, Function-ஐ நீங்க எப்போ கூப்பிட்டாலும் அது வேலை செய்யும், முழுசா Hoist ஆகிடும்).

**2. `var` (பழைய காலி பாக்ஸ்):**
நீங்க "பாக்ஸ்ல என்ன இருக்கு காட்டுங்க?" அப்படின்னு கேக்குறீங்க. மேஜிசியன் பாக்ஸை ஓபன் பண்ணுவார், ஆனா பாக்ஸ் காலியா இருக்கும்! உள்ளே பொருள் (Value) இருக்காது. "பாக்ஸ் இருக்கு ஆனா உள்ள ஒன்னும் இல்லை (Undefined)" அப்படின்னு சொல்லுவார்.

**3. `let` & `const` (கோபப்படும் மேஜிசியன்):**
நீங்க "புது டப்பாவை திறங்க!" அப்படின்னு அவசரப்படுறீங்க. மேஜிசியனுக்கு கோபம் வந்துடும். "இன்னும் நான் அந்த மேஜிக்கை ஆரம்பிக்கவே இல்லை, அதுக்குள்ள கேட்டா எப்படி? வெயிட் பண்ணு!" அப்படின்னு திட்டிடுவார் (Error அடிக்கும்).

---

### இதை சிம்பிள் Code-ல பார்ப்போம்:

```javascript
// 1. Function (மேஜிக் முயல் - எப்போ கூப்பிட்டாலும் வரும்)
magicTrick(); // Output: "முயல் குட்டி!"

function magicTrick() {
    console.log("முயல் குட்டி!");
}

// 2. var (காலி பாக்ஸ்)
console.log(oldBox); // Output: undefined
var oldBox = "பழைய பொருள்";

// 3. let / const (கோபப்படும் மேஜிசியன்)
console.log(newBox); // Error: Cannot access 'newBox' before initialization
let newBox = "புது பொருள்";

```

**இன்டர்வியூல சொல்ல வேண்டிய முக்கியமான பாஸ்வேர்ட் 🔑:**

இன்டர்வியூல `let` அல்லது `const`-ஐ முன்னாடியே கூப்பிட்டா Error வருது இல்லையா? அந்த Error வர்ற டைம்க்கு பேரு **"Temporal Dead Zone (TDZ)"**. இந்த ஒரு வார்த்தையை நீங்க இன்டர்வியூல சொல்லிட்டீங்கன்னா, "பையன் டெக்னிக்கலா ரொம்ப ஸ்ட்ராங்கா இருக்கான்!" அப்படின்னு கன்பார்ம் பண்ணிடுவாங்க.

எப்படி ப்ரோ, இந்த மேஜிக் ஷோ கதை கிளியரா இருக்கா?
