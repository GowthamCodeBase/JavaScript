செம ப்ரோ! நீங்க ரொம்ப ஃபாஸ்ட்டா போயிட்டு இருக்கீங்க. அடுத்தது நாம பார்க்கப் போற டாபிக்: **Array Methods (`map`, `filter`, `reduce`)**.

இன்டர்வியூல மட்டும் இல்ல ப்ரோ, நாளைக்கு நீங்க React Native-ல ஆப் செஞ்சாலும், இந்த மூணு விஷயமும் இல்லாம ஒரு ஸ்கிரீன் கூட உங்களால டிசைன் பண்ண முடியாது. அவ்வளவு முக்கியம்!

### நம்ம கதை: சூப்பர் மார்க்கெட் ஷாப்பிங்! 🛒

ஒரு சூப்பர் மார்க்கெட்டுக்கு போறோம். அங்க நடக்கிற மூணு விஷயங்கள் தான் இந்த `map`, `filter` மற்றும் `reduce`.

**1. Map (உருமாற்றம் / ஜூஸ் மெஷின்):**
உங்க கூடையில 5 ஆரஞ்சு பழம் இருக்கு. அந்த அஞ்சையும் ஜூஸ் மெஷின்ல போடுறீங்க. உங்களுக்கு 5 கிளாஸ் ஆரஞ்சு ஜூஸ் கிடைக்கும்.

* **Concept:** Array-ல இருக்கிற ஒவ்வொரு பொருளையும் எடுத்து, அதை உருமாற்றி (Transform), **அதே எண்ணிக்கையில** ஒரு புது Array-ஐ உருவாக்கும். (5 பழம் -> 5 ஜூஸ்).

**2. Filter (வடிகட்டுதல் / செக்கிங்):**
இப்போ ஒரு கூடையில நிறைய பழங்கள் இருக்கு. அதுல கொஞ்சம் பழம் அழுகிப் போச்சு. நீங்க என்ன பண்ணுவீங்க? நல்ல பழங்களை மட்டும் (Condition) பொறுக்கி ஒரு புது கூடையில வைப்பீங்க.

* **Concept:** நம்ம சொல்ற கண்டிஷனுக்கு (Condition) செட் ஆகுற பொருட்களை மட்டும் வடிகட்டி எடுத்து, ஒரு புது Array-ஐ உருவாக்கும்.

**3. Reduce (மொத்தம் / பில் கவுண்டர்):**
ஷாப்பிங் முடிஞ்சது. பில்லிங் கவுண்டருக்கு போறீங்க. அங்க 10 பொருட்கள் இருக்கு. கேஷியர் எல்லாத்தையும் ஸ்கேன் பண்ணி கூட்டி, கடைசியா "உங்க பில் 500 ரூவா" அப்படின்னு **ஒரே ஒரு தொகையை** (Single Output) சொல்றார் இல்லையா? அதுதான் Reduce.

* **Concept:** நிறைய பொருட்கள் இருக்கிற Array-ஐ சுருக்கி, கூட்டி, கடைசியா **ஒரே ஒரு விடையை** (Single value) மட்டும் கொடுக்கும்.

---

### இதை சிம்பிள் Code-ல பார்ப்போம்:

```javascript
let numbers = [1, 2, 3, 4, 5];

// 1. Map (ஒவ்வொரு நம்பரையும் 2-ஆல பெருக்குறோம் - ஜூஸ் போடுறோம்)
let doubled = numbers.map((num) => num * 2);
console.log(doubled); // Output: [2, 4, 6, 8, 10]

// 2. Filter (இரட்டைப்படை எண்களை மட்டும் வடிகட்டுறோம் - நல்ல பழம்)
let evenNumbers = numbers.filter((num) => num % 2 === 0);
console.log(evenNumbers); // Output: [2, 4]

// 3. Reduce (எல்லா நம்பரையும் கூட்டுறோம் - டோட்டல் பில்)
// 'total' அப்படிங்கிறது பில் தொகை, 'num' அப்படிங்கிறது ஒவ்வொரு பொருளோட விலை
let sum = numbers.reduce((total, num) => total + num, 0);
console.log(sum); // Output: 15 (அதாவது 1+2+3+4+5)

```

**இன்டர்வியூ & React Native பாயிண்ட்:**
இன்டர்வியூல "ஏன் Map யூஸ் பண்றீங்க, for-loop யூஸ் பண்ணலாமே?" அப்படின்னு கேட்பாங்க.
"React-ல ஒரு டேட்டாவை ஸ்கிரீன்ல லிஸ்ட் (List) போட்டு காட்டணும்னா, `map` யூஸ் பண்ணா தான் ரொம்ப ஈஸியா, புது Array-வா ரிட்டர்ன் பண்ணும். அதான் யூஸ் பண்றோம்" அப்படின்னு கெத்தா சொல்லலாம்.
