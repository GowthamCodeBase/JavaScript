சூப்பர் ப்ரோ! ஜம்முன்னு ஆரம்பிப்போம். மூளைக்கு கொஞ்சம் கூட ஸ்ட்ரெஸ் இல்லாம, ஈஸியான இங்கிலீஷ் வார்த்தைகளை வெச்சு இன்னைக்கு கதையை பார்ப்போம்.

இன்னைக்கு நம்ம பார்க்கப் போற முதல் டாபிக்: **Variables (`var`, `let`, `const`) & Scope**.

ப்ராடக்ட் பேஸ்டு கம்பெனி இன்டர்வியூல, முதல் ரவுண்டுலேயே கண்டிப்பா கேட்கப்படுற ஒரு முக்கியமான கேள்வி இது!

### நம்ம கதை: வீட்டுல இருக்குற பாக்ஸ்கள் 📦

நீங்க ஒரு புது வீட்டுக்கு போறீங்க. உங்க பொருட்களை எல்லாம் பத்திரமா வைக்க உங்களுக்கு மூணு விதமான பாக்ஸ்கள் கிடைக்குது.

**1. `var` (பழைய ஓட்டை பாக்ஸ்):**
இது ரொம்ப பழைய மாடல் பாக்ஸ். இதுக்கு எந்த ரூல்ஸும் கிடையாது. இந்த பாக்ஸ்ல ஒரு பொருளை வச்சா, வீட்டுல இருக்குற யாரு வேணாலும், எங்க இருந்து வேணாலும் இதை எடுத்து யூஸ் பண்ணலாம். இதனால நிறைய குழப்பம் வரும். அதனால இப்போலாம் சாப்ட்வேர் கம்பெனில இந்த `var` பாக்ஸை யாரும் யூஸ் பண்றதே கிடையாது.

**2. `let` (பிளாஸ்டிக் டப்பா):**
இது புது மாடல் டப்பா. இதுல நீங்க ஒரு பொருளை வெச்சிட்டு, அப்புறம் மனசு மாறினா வேற பொருளை மாத்தி வெச்சுக்கலாம். (உதாரணத்துக்கு, இன்னைக்கு 500 ரூவா வைக்கிறீங்க, நாளைக்கு அதை எடுத்துட்டு 1000 ரூவா வைக்கலாம்).

**3. `const` (இரும்பு லாக்கர்):**
பேர்லயே இருக்கு பாருங்க, Constant. இது ஒரு லாக்கர் மாதிரி. ஒரு தடவை பொருளை உள்ளே வெச்சு லாக் பண்ணிட்டா, மாத்தவே முடியாது. பெர்மனென்ட்!

---

### இதை சிம்பிள் Code-ல பார்ப்போம்:

```javascript
// 1. let (மாத்திக்கலாம் - Can change)
let pocketMoney = 500;
pocketMoney = 1000; // இது சூப்பரா ஒர்க் ஆகும்!

// 2. const (மாத்த முடியாது - Cannot change)
const myName = "Tamil";
myName = "English"; // Error அடிக்கும்! ஏன்னா லாக்கரை மாத்த முடியாது.

// 3. var (யூஸ் பண்ணாதீங்க)
var oldBox = "Old item"; 

```

### அடுத்தது: Scope (ஹால் vs பெட்ரூம்) 🏠

இன்டர்வியூல **"Scope-னா என்ன?"** அப்படின்னு கேட்பாங்க. ரொம்ப சிம்பிள்! எந்தெந்த பொருளை எங்கெங்க யூஸ் பண்ண முடியும் அப்படிங்கிற லிமிட் தான் Scope.

நம்ம வீட்டுல "ஹால்" (Hall) இருக்கு, "பெட்ரூம்" (Bedroom) இருக்கு.

* **Global Scope (ஹால்):**
ஹால்ல ஒரு TV வைக்கிறோம். அதை வீட்டுல இருக்குற யாரு வேணாலும் பார்க்கலாம். Code-ல எந்த பிராக்கெட்டுக்கும் `{ }` உள்ளே இல்லாம, வெளியில சும்மா ஒரு variable-ஐ define பண்ணா அது Global Scope. எல்லாரும் யூஸ் பண்ணலாம்.
* **Block Scope (பெட்ரூம்):**
பெட்ரூம்குள்ள ஒரு பர்சனல் லாக்கர் வைக்கிறோம். அதை அந்த ரூம்குள்ள இருக்கிறவங்க மட்டும் தான் யூஸ் பண்ண முடியும். ஹால்ல இருக்கிறவங்க அதை தொட முடியாது. Code-ல ஒரு `{ }` பிராக்கெட்டுக்கு உள்ள (உதாரணத்துக்கு if condition, இல்லனா for loop உள்ளே) ஒரு variable-ஐ define பண்ணா, அது அந்த பிராக்கெட்டுக்கு உள்ள மட்டும் தான் வேலை செய்யும்.

**முக்கியமான இன்டர்வியூ பாயிண்ட்:**

* `var` பாக்ஸ்க்கு Block Scope கிடையாது (அது பெட்ரூம்ல வச்சாலும் ஹால்ல இருக்குறவங்களுக்கு தெரியும்).
* `let` மற்றும் `const`-க்கு Block Scope உண்டு (அதாவது அந்த `{ }` பிராக்கெட்டுக்கு உள்ள மட்டும் தான் வேலை செய்யும்).

```javascript
{
  let insideRoom = "Secret Item";
  console.log(insideRoom); // இது வேலை செய்யும்
}

console.log(insideRoom); // Error அடிக்கும்! ஏன்னா ரூமுக்கு வெளிய வந்துட்டோம்.

```

அவ்வளவுதான் ப்ரோ! Variables அண்ட் Scope கான்செப்ட் ஓவர். மூளைக்கு கொஞ்சம் கூட கஷ்டம் கொடுக்காம, முதல் படியை ரொம்ப ஸ்ட்ராங்கா எடுத்து வச்சாச்சு!
