சூப்பர் ப்ரோ! அடுத்த டாபிக் போயிடலாம்.

இன்னைக்கு இன்டர்வியூல நிறைய பேரை கன்பியூஸ் பண்ற, ஆனா ரொம்ப ரொம்ப ஈஸியான ஒரு டாபிக் பார்க்கப் போறோம்: **Closures (க்ளோஷர்)**.

### நம்ம கதை: பாட்டி சொன்ன ரகசியம்! 👵🤫

ஒரு பாட்டி இருக்காங்க. அவங்களுக்கு மட்டும் தான் ஒரு சூப்பரான "பிரியாணி மசாலா ரகசியம்" தெரியும். அந்த பாட்டி, தன்னோட பேரன் கிட்ட அந்த ரகசியத்தை சொல்லிக் கொடுக்குறாங்க.

கொஞ்ச நாள் கழிச்சு பாட்டி ஊருக்கு போயிட்டாங்க. இப்போ பாட்டி அங்க இல்ல, ஆனா பேரனுக்கு அந்த ரகசியம் இன்னும் நல்லா **ஞாபகம் இருக்கு!**

இதுதான் ப்ரோ **Closure!**

டெக்னிக்கலா சொல்லணும்னா: ஒரு Function (பாட்டி), தனக்கு உள்ளே இன்னொரு Function-ஐ (பேரன்) வெச்சிருக்கும். Outer function (பாட்டி) தன்னோட வேலையை முடிச்சிட்டு போன பிறகும் (Execution முடிஞ்ச பிறகும்), Inner function (பேரன்) அந்த outer function-ஓட டேட்டாவை (ரகசியத்தை) **ஞாபகம் வெச்சிருக்கும்**. இந்த ஞாபக சக்திக்கு பேருதான் Closure.

---

### இதை சிம்பிள் Code-ல பார்ப்போம்:

```javascript
function patti() {
    let secret = "பிரியாணி மசாலா சீக்ரெட்"; // இது பாட்டியோட ரகசியம்

    function peran() {
        console.log(secret); // பேரன் அந்த ரகசியத்தை யூஸ் பண்றான்
    }

    return peran; // பாட்டி பேரனை மட்டும் விட்டுட்டு கிளம்புறாங்க
}

let memory = patti(); // பாட்டியோட வேலை முடிஞ்சது (Function execution over)

// இப்போ பாட்டி இல்ல, ஆனா...
memory(); // Output: பிரியாணி மசாலா சீக்ரெட்

```

**இன்டர்வியூல கேட்பாங்க: "இதனால என்ன யூஸ் ப்ரோ?"**
**பதில்:** "Data Privacy" (டேட்டா பாதுகாப்பு). வெளியில இருந்து யாராவது வந்து அந்த `secret` அப்படிங்கிற டேட்டாவை மாத்த ட்ரை பண்ணா, மாத்த முடியாது. அந்த பேரன் (Inner function) மூலமா மட்டும் தான் அதை ஆக்சஸ் பண்ண முடியும். ஒரு பேங்க் லாக்கர் மாதிரி டேட்டாவை பாதுகாப்பா வெச்சுக்க இது ரொம்ப யூஸ் ஆகும்.

அவ்வளவுதான்! Closure முடிஞ்சது. இன்டர்வியூல கேட்டா இதே மாதிரி கூலா பாட்டி-பேரன் கதையை மனசுல வெச்சுகிட்டு சொல்லுங்க, செலக்ட் ஆகிடுவீங்க!

எப்படி ப்ரோ, இந்த கான்செப்ட் ஈஸியா உள்ள போயிடுச்சா? அடுத்து, JavaScript-ல ரொம்ப ரொம்ப முக்கியமான **"Event Loop" (ஹோட்டல் வெயிட்டர் கதை)** டாபிக் பார்க்கலாமா?
