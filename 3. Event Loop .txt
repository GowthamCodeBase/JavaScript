செம ஸ்பீடு ப்ரோ! வாங்க அடுத்த டாபிக் போவோம்.

ப்ராடக்ட் பேஸ்டு கம்பெனி இன்டர்வியூல, ரொம்ப ரொம்ப முக்கியமான, நிறைய பேரை கன்பியூஸ் பண்ற டாபிக் இது: **Event Loop (ஈவென்ட் லூப்)**.

### நம்ம கதை: ஹோட்டல் வெயிட்டரும் தந்தூரி சிக்கனும்! 🧑‍🍳

ஜாவாஸ்கிரிப்ட் அப்படிங்கிறது ஒரு சின்ன ஹோட்டல் மாதிரி. அங்க **ஒரே ஒரு வெயிட்டர்** தான் இருக்கார். (இதனால தான் JavaScript-ஐ "Single-threaded" அப்படின்னு சொல்லுவாங்க. ஒரு நேரத்துல ஒரு வேலை தான் செய்ய முடியும்).

இப்போ அந்த வெயிட்டர் எப்படி எல்லா வேலையையும் மேனேஜ் பண்றார்னு பார்ப்போம்:

**1. உடனடி வேலை (Synchronous / Call Stack):**
ஒரு டேபிள்ல "ஒரு பாட்டில் தண்ணி குடுங்க" அப்படின்னு கேக்குறாங்க. வெயிட்டர் உடனே தண்ணிய கொடுத்துட்டு அடுத்த டேபிளுக்கு போயிருவார். இது ரொம்ப ஸ்பீடா நடக்கும்.

**2. டைம் ஆகுற வேலை (Asynchronous / Web API):**
அடுத்த டேபிள்ல "ஒரு தந்தூரி சிக்கன்" ஆர்டர் பண்றாங்க. இது ரெடி ஆக 20 நிமிஷம் ஆகும். நம்ம வெயிட்டர் முட்டாள்தனமா அந்த 20 நிமிஷமும் கிச்சன் வாசல்லயே காத்துகிட்டு நிக்க மாட்டார். ஆர்டரை கிச்சன் மாஸ்டர் கிட்ட கொடுத்துட்டு, அடுத்த டேபிளுக்கு ஆர்டர் எடுக்க போயிடுவார். (நாம யூஸ் பண்ற `setTimeout`, API fetch எல்லாமே இந்த தந்தூரி சிக்கன் மாதிரி தான்).

**3. வெயிட்டிங் ஏரியா (Callback Queue):**
20 நிமிஷம் கழிச்சு, தந்தூரி சிக்கன் ரெடி! மாஸ்டர் அதை எடுத்து "டெலிவரி கவுண்டர்ல" (Queue) வெச்சிடுவார்.

**4. மேனேஜர் செக்கிங் (Event Loop):**
இங்க தான் நம்ம "Event Loop" வர்றாரு! இவர் ஹோட்டல் மேனேஜர் மாதிரி. இவர் எப்பவும் ரெண்டு விஷயத்தை செக் பண்ணிகிட்டே இருப்பார்:

* "நம்ம வெயிட்டர் ஃப்ரீயா இருக்காரா?" (Call stack empty-ஆ இருக்கா?)
* "டெலிவரி கவுண்டர்ல ஏதாவது சாப்பாடு ரெடியா இருக்கா?" (Queue-ல ஏதாவது இருக்கா?)

வெயிட்டர் எல்லா டேபிள் ஆர்டரையும் முடிச்சிட்டு ஃப்ரீ ஆனதும், மேனேஜர் (Event Loop) அந்த தந்தூரி சிக்கனை எடுத்து வெயிட்டர் கிட்ட கொடுத்து, டேபிள்ல சர்வ் பண்ண சொல்லுவார்.

---

### இதையே Code-ல பார்ப்போம்:

```javascript
console.log("1. ஒரு பாட்டில் தண்ணி"); // உடனே நடக்கும்

// இது தந்தூரி சிக்கன் (2 செகண்ட் டைம் ஆகும்)
setTimeout(() => {
    console.log("2. தந்தூரி சிக்கன் ரெடி!"); 
}, 2000);

console.log("3. அடுத்த டேபிள் ஆர்டர்"); // உடனே நடக்கும்

```

**Output எப்படி வரும்?**

1. ஒரு பாட்டில் தண்ணி
2. அடுத்த டேபிள் ஆர்டர்
3. தந்தூரி சிக்கன் ரெடி! (கடைசியா தான் வரும், ஏன்னா Event loop வெயிட்டர் ஃப்ரீ ஆகுற வரைக்கும் வெயிட் பண்ணும்).

அவ்வளவுதான் ப்ரோ! Event Loop அப்படிங்கிறது ஒரு மேனேஜர் மாதிரி, வெயிட்டரும் கிச்சனும் கரெக்டா வேலை செய்யுதான்னு செக் பண்றது தான் அவரோட வேலை.

இந்த ஹோட்டல் கதை ஈஸியா புரிஞ்சதா ப்ரோ? அடுத்து, JS இன்டர்வியூல அடிக்கடி கேட்கப்படுற **Hoisting (ஹாய்ஸ்டிங்)** கான்செப்ட்டை ஒரு மேஜிக் ஷோ கதை மாதிரி பார்க்கலாமா?
