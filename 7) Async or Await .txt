கலக்கிட்டீங்க ப்ரோ! ஜாவாஸ்கிரிப்ட் அஜெண்டாவோட **கடைசி டாபிக்** வந்தாச்சு. இதை முடிச்சிட்டா நீங்க Pure JS-ல ரொம்ப ஸ்ட்ராங் ஆகிடுவீங்க!

நம்ம பார்க்கப் போற டாபிக்: **Async / Await**.
இது நம்ம நேத்து பார்த்த "பிரியாணி Promise" கதையோட பார்ட்-2!

### நம்ம கதை: ஸ்விக்கி டெலிவரி பாய் 🛵

நேத்து நாம Promise படிக்கும்போது, பிரியாணி கிடைச்சா என்ன செய்யணும்னு சொல்ல `.then()` யூஸ் பண்ணோம். ஆனா, ரியல்-டைம் ப்ராஜெக்ட்ல நிறைய `.then()` போட்டா கோட் பாக்க ரொம்ப குழப்பமா இருக்கும். அதனாலதான் இப்போ எல்லாரும் `async / await` யூஸ் பண்றாங்க. இது படிக்கிறதுக்கு சாதாரண இங்கிலீஷ் மாதிரியே இருக்கும்.

நீங்க ஸ்விக்கில பிரியாணி ஆர்டர் பண்றீங்க. பிரியாணி வர 30 நிமிஷம் ஆகும்.

* **Async (டைம் எடுக்கும் வேலை):** இந்த மொத்த வேலையும் கொஞ்சம் டைம் எடுக்கும்னு கம்ப்யூட்டருக்கு முன்னாடியே சொல்றது.
* **Await (காத்திருப்பு):** பிரியாணி கைக்கு வர்ற வரைக்கும், நீங்க தட்டை எடுத்துக்கிட்டு சாப்பிட உக்கார மாட்டீங்க. "பிரியாணி டெலிவரி ஆகுற வரைக்கும் அந்த இடத்துலயே கொஞ்சம் வெயிட் பண்ணு (await)" அப்படின்னு கோடை நிறுத்தி வைப்பது.

---

### இதை சிம்பிள் Code-ல பார்ப்போம்:

```javascript
// 'async' போட்டா, உள்ளே டைம் எடுக்குற வேலை நடக்கப் போகுதுனு அர்த்தம்
async function getSwiggyOrder() {
    console.log("1. பிரியாணி ஆர்டர் போட்டாச்சு...");

    // பிரியாணி கைக்கு வர்ற வரைக்கும் இங்கயே கோட் வெயிட் பண்ணும்
    let biryani = await fetch("https://swiggy.com/get-biryani"); 
    
    // பிரியாணி வந்த பிறகு தான் அடுத்த லைனுக்கே போகும்!
    console.log("2. பிரியாணி வந்தாச்சு! சாப்பிடலாம் 🍗");
}

getSwiggyOrder();

```

**இன்டர்வியூ பாயிண்ட் (The Catch):**
இன்டர்வியூல, "சரி ப்ரோ, நடுவுல மழை வந்து ஸ்விக்கி பாய் ஆர்டரை கேன்சல் பண்ணிட்டா (Error) என்ன பண்ணுவீங்க?" அப்படின்னு கேட்பாங்க.

அதுக்கு `try...catch` யூஸ் பண்ணனும்னு சொல்லணும்.

```javascript
async function getSwiggyOrder() {
    try {
        // எல்லாம் நல்லபடியா நடந்தா (Success)
        let biryani = await fetch("https://swiggy.com/get-biryani");
        console.log("பிரியாணி வந்தாச்சு! சாப்பிடலாம் 🍗");
    } catch (error) {
        // ஏதாவது தப்பா நடந்தா (Failure)
        console.log("சாரி ப்ரோ, மழைனால ஆர்டர் கேன்சல் ஆயிடுச்சு 😭");
    }
}

```

**React Native-ல இதோட யூஸ் என்ன?**
நாளைக்கு நீங்க உங்க ஆப்ல, ஒரு யூசரோட டேட்டாவை சர்வர்ல இருந்து (API மூலம்) கொண்டு வரணும்னா, இந்த `async / await` இல்லாம பண்ணவே முடியாது. ஒரு முழு ஆப்பும் இதை நம்பி தான் ஓடுது!
